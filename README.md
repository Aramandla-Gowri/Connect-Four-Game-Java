# Connect Four Game in Java

## 📌 Project Overview
This project is a console-based Connect Four Game developed in Java as the Week 4 Final Task of the INTERPE Java Development Internship.

The game allows two players to take turns dropping their pieces into a 6×7 grid. The first player to connect four of their symbols horizontally, vertically, or diagonally wins the game.

---

## 🚀 Features

- Two-player gameplay
- 6×7 game board
- Automatic piece dropping mechanism
- Input validation for invalid moves
- Horizontal win detection
- Vertical win detection
- Diagonal win detection
- Console-based user interface
- Object-Oriented Programming implementation
